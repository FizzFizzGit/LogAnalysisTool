# ログ検索ツール v1.3.3 (FF14 Special Edition)

FF14のバイナリログ解析に最適化された、高速・軽量な多機能ログ検索ツールです。  
テキストファイルおよびバイナリ形式ログに対応し、直感的なGUIとインスペクターパネルで目的のログをすばやく検索・分析できます。

---

## ✨ 主な特長

- **FF14バイナリログ最適化**: ログ特有の制御タグやバイナリ構造を解析し、タイムスタンプ付きの読みやすいテキストに自動変換します。
- **下部HEXインスペクター**: 検索結果一覧をスッキリ見やすく保ちつつ、選択した行の生バイト（16進数データ）を下部パネルでいつでも確認できます。
- **プライバシー＆メモリ配慮**: ローカルの絶対パス（`FullFilePath`）を保持・出力しない軽量設計です。
- **データ出力**: 検索結果を文字化け防止BOM付きCSV、またはTSV形式で一括保存可能です。

## 📦 使い方

### PowershellへのPathが通っていることが前提

- 通っていない場合はSystem環境変数で`Path`に`C:\Windows\System32\WindowsPowerShell\v1.0\`を登録する。

---

1. ### exe起動

   - ダウンロードしたLogAnalysisTool.exeをダブルクリックして起動します。

2. ### run.bat起動

   - LogAnalysisTool.zipを解凍して、同じフォルダ内に置いたrun.batをダブルクリック。

3. ### powershellから直接起動

   - LogAnalysisTool.zipを解凍して、powershellターミナルから直接起動する。
   - 例：powershell.exe -ExecutionPolicy Bypass -File .\main.ps1

---

### 1. 起動方法

ダウンロードしたファイルを解凍し、フォルダ内にある **`run.bat`** をダブルクリックしてください。

（PowerShellウィンドウや実行ポリシーの警告を出さずにツールが立ち上がります）

### 2. 検索の手順

1. **フォルダ選択**: 画面右上の「参照」ボタンを押し、検索したいログファイルが格納されているフォルダを選択します。
2. **キーワード入力**: 検索したい文字を入力します（空欄のまま検索すると全ログ行を取得します）。
3. **オプション設定**:

   - **FF14ログ最適化** (推奨): FF14バイナリログを解読して表示します。
   - **修復して表示**: 文字化けが発生しているログテキストの自動復元を試みます。

4. **検索開始**: 「検索」ボタンをクリックするとリアルタイムで検索結果が一覧に表示されます。

### 3. 結果の確認・活用

- **HEXデータの確認**: 一覧から気になる行をクリックすると、画面下部の「生バイト (HEX)」欄にその行の16進数データが表示されます。
- **コピー**: 右クリックメニュー、または `Ctrl + C` で選択行のデータをクリップボードにコピーできます。
- **一時中断 / リセット**: 検索中に「一時中断」ボタンで処理を停止・再開できます。「リセット」ボタンで画面をクリアします。
- **保存**: 「保存」ボタンから結果をCSVファイルまたはテキスト（TSV）ファイルとして保存できます。
